# TC16 教学视频页面设计

## 目标

将 `TC16教学视频.zip` 中的 10 个 MP4 教程发布到 TC16 更新网站，让用户可在电脑和手机浏览器中按顺序观看。

## 页面结构

- 保持现有软件下载首页不变，仅在顶部导航增加“教学视频”入口。
- 新增独立页面 `tutorials.html`，显示页面标题和 10 个教程播放器。
- 每个教程包含序号、中文标题和原生 HTML5 视频控件。
- 小屏幕使用单列布局，宽屏使用双列布局。

## 视频资源

- 视频解压到 `assets/videos/`。
- 文件名改为 ASCII 小写短横线格式，避免中文 URL 的兼容问题。
- 使用 MP4 格式，播放器设置 `controls` 和 `preload="metadata"`，避免页面打开时下载全部视频内容。

## 验证

- 检查 10 个页面引用均存在且文件非空。
- 检查 HTML 中不存在失效的本地资源路径。
- 在本地 HTTP 服务中打开首页和教程页，验证桌面与移动端布局、导航和播放器加载。
- 推送后检查 GitHub Pages 线上页面可访问。
